从一张合影，到一份完整名单。

三步，省下逐个确认的时间。

01 / 管理员准备

上传照片，框出人脸

浏览器自动检测人脸；漏掉了可以补框，位置不准可以拖动调整。导入成员名单并分配验证码。

02 / 成员认领

分享链接，手机填名

成员凭姓名与验证码登录，双指缩放找到自己，轻点人脸填写。只能填写空位或自己填过的位置。

03 / 管理员导出

按排按位，整理成名单

随时查看填写进度，导出按「第几排第几位」排序的名单、未填写人员、操作日志与标注图。

Group Photo Namer is a self-hosted tool for group photo labeling and name collection. Detect faces in the browser, let participants name their own faces on mobile, and export a photo roster ordered by row and position. Built for class photos, graduation photos, workshops and team events.

照片留在自己的服务器

face-api.js 在浏览器内检测人脸，不把照片传给第三方识别服务。姓名由成员填写，不做自动身份识别。

一次部署，多个合影项目

为不同活动分别设置名称、简介和图标。各项目的照片、人脸框、名单与日志独立保存。

简单运行，实时保存

Node.js 内置 HTTP 与 SQLite，免安装 npm 依赖、无需构建。SQLite WAL 实时落盘，成员端定时同步。

GET STARTED

在你自己的环境里运行。

准备 Node.js ≥ 22.5，克隆项目即可启动。首次运行会在终端显示随机管理员码。

你可能想知道

可以直接在这个页面上传合影吗？

这里用于了解项目与获取源码。完整应用需要部署到自己的电脑或服务器；希望多人通过手机访问时，需要提供可访问的服务地址。

会自动识别每个人是谁吗？

不会。系统只检测并框出人脸，姓名由成员自己填写。人脸检测模型需要联网加载，照片不会发给第三方识别服务。

同名成员会互相覆盖吗？

支持重名，使用不同验证码的成员各自独立填写。成员不能改动他人已填写的位置。

开源后，我的照片和名单也会公开吗？

公开的是程序源码。你部署后的照片和名单保存在自己的数据库中；不要把 data/ 数据库提交到公开仓库，并请按部署文档配置 HTTPS 和定期备份。
